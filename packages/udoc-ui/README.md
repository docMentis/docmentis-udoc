# @docmentis/udoc-ui

**The shared document UI foundation for docMentis viewer and editor.**

This package contains the common interface and integration foundation used by [`@docmentis/udoc-viewer`](https://www.npmjs.com/package/@docmentis/udoc-viewer) and [`@docmentis/udoc-editor`](https://www.npmjs.com/package/@docmentis/udoc-editor).

It is a supporting package within the udoc ecosystem, **not a standalone document viewer or editor**. If you're embedding documents in an application, start with udoc-viewer or udoc-editor instead.
