# udoc developer documentation

The developer documentation site for docMentis udoc, including usage guides and API references for the viewer, editor, Node.js integration, CLI, and server ecosystem.

This workspace is part of the [docMentis udoc monorepo](https://github.com/docMentis/docmentis-udoc) and is **not published to npm**.

From the repository root:

```sh
npm install
npm run build
npm run docs
```

For package-specific introductions, start with the README in the relevant package directory.
