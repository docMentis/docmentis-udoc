# @docmentis/udoc-demo

**A demo app showcasing the docMentis document viewer and editor.**

See [`@docmentis/udoc-viewer`](https://www.npmjs.com/package/@docmentis/udoc-viewer) and [`@docmentis/udoc-editor`](https://www.npmjs.com/package/@docmentis/udoc-editor) at work on PDF, Word, PowerPoint, Excel, and image files: view documents, edit them, and co-edit them side by side.
